# Reguli de colaborare

Discutăm respectuos, criticăm schimbările propuse și explicăm argumentele tehnice. Nu sunt acceptate hărțuirea, discriminarea, amenințările, publicarea datelor personale sau folosirea proiectului pentru atacuri asupra altor persoane ori servicii.

În review, cererile de schimbare trebuie să fie concrete și proporționale cu riscul. Menținem conversațiile accesibile și oferim context contributorilor noi.

Incidentele pot fi raportate privat administratorilor repository-ului sau prin contactul operatorului. Administratorii pot modera conversațiile și limita participarea pentru a proteja colaboratorii. Nu se publică datele persoanei care raportează un incident fără acordul său.
